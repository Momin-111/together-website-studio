# Together Website Studio

A bilingual English/Arabic marketing website for Together, a UK-based website studio for small businesses.

## Included

- React + Vite frontend in artifacts/business-website-studio
- English/Arabic language toggle with RTL layout
- Responsive marketing sections, package cards, FAQ accordion, and enquiry form
- Shared pnpm workspace structure

## Run locally

pnpm install
pnpm --filter @workspace/business-website-studio run dev
